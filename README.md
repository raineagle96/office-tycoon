# Office Tycoon

Game mô phỏng quản lý văn phòng 2D, chạy trên trình duyệt.

Người chơi làm quản lý: tuyển và sắp xếp nhân viên, giao việc để hoàn thành dự án đúng hạn và giữ công ty có lãi.

## Trạng thái

Đang trong giai đoạn thiết kế (SDD). Code sẽ được bổ sung dần theo tài liệu thiết kế.

## Công nghệ dự kiến

- HTML + JavaScript, chạy trực tiếp trên trình duyệt, không cần server
- Lưu game bằng localStorage
